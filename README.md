# Zaki Ansyari — Home / Gallery / Songs / Contact
Website personal responsif terinspirasi dari screenshot yang diberikan, memakai tema hitam/navy dan emas. Berisi frontend statis, Google Sheets + Google Apps Script, login admin Google, galeri, daftar lagu, dan formulir kontak.

Lihat `PANDUAN-DEPLOY-LENGKAP.md` untuk panduan deploy dari awal sampai online.
