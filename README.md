# Zaki Ansyari — Premium Personal Portfolio

Website statis responsif bertema hitam dengan aksen biru angkasa. Fitur: profil interaktif, keahlian, proyek, timeline, sertifikat/CV, galeri, musik, buku tamu dengan moderasi, statistik kunjungan sederhana, formulir kontak, kartu kontak digital, dan dashboard privat dengan Google Sign-In. Data disimpan di Google Sheets melalui Google Apps Script; foto dan dokumen dapat diunggah langsung ke Google Drive dari dashboard.

Mulai dari `PANDUAN-DEPLOY-LENGKAP.md`. Ganti placeholder konfigurasi sebelum deploy. Login admin memerlukan OAuth Client ID dan email yang diizinkan.
